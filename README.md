# ant-pheromone

Python reproduction companion for the single-pheromone model of big-headed
ant foraging described by Saund and Friedman. The model compares predicted
branch preferences with observations transcribed from Dussutour et al.

- [User guide](docs/README.md) covers setup, model entry points, and verification.
- [Reproduction manuscript](docs/manuscript/README.md) covers methods, evidence,
  and the pinned PDF build.

[Saund and Friedman (2023)](https://doi.org/10.1016/j.cogsys.2023.02.005) ·
[Dussutour et al. (2009)](https://doi.org/10.1242/jeb.029827)
