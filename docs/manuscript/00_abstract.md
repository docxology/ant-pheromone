# Abstract

This software companion describes how to replay a deterministic model of
branch selection during big-headed ant foraging. The model represents one
trail signal and uses separate deposition rates for exploration and
exploitation. The repository includes transcribed branch-preference
observations, parameter bundles, and functions for the trail-decay and
food-switch experiments. A regenerated comparison figure shows how the
predictions relate to those observations and identifies the inputs needed
to repeat the calculation.
