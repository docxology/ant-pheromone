# Experimental comparisons

Dussutour and colleagues studied trail-dependent branch selection in
big-headed ants using a Y-junction. In the trail-decay experiments the
branch tagged E+F had previously been explored and used for foraging.
The comparison branch had either been explored without food (E) or
left unmarked (N). In the dynamic experiment the food was moved from
branch A to branch B and back [@dussutour2009].

Saund and Friedman proposed a model in which the same signal is deposited
during exploration and exploitation, with more deposited during
exploitation [@saund2023]. The model tests whether these assumptions can
account for the reported preference patterns. The two studies provide
the experimental and modeling contexts for the software replay.
