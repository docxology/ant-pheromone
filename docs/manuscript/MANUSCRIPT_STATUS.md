# Manuscript status — ant-pheromone

## Repo type
Single-program research-code repository (evidence: `pheromoneModel.py`, a
background/citation `README.md`, an `archives/` directory; no `manuscript/`
directory, no packaging metadata, no analysis-output tree).

## Why no publication-target manuscript applies today
The associated paper ("A Single-Pheromone Model Accounts for Empirical Patterns
of Ant Colony Foraging Previously Modeled Using Two Pheromones", submitted to
Cognitive Systems Research per README.md) is managed outside this repository.
The repo itself is the model program and its provenance record, not a
manuscript workspace; creating template section stubs here would duplicate
content that lives with the journal submission.

## What would trigger creating one
If the repo becomes the reproducibility companion for a published version
(figures, generated outputs, and a section-structured manuscript under the
template standard), a `manuscript/` directory with `config.yaml` and section
files should be created.
